# wan-i2v skill source

This repository packages the `wan-i2v` Codex skill for installation through the Codex Skill Installer.

Install target path inside the repo:

- `skills/wan-i2v`

Example installer command:

```powershell
python C:\Users\suzu_\.codex\skills\.system\skill-installer\scripts\install-skill-from-github.py --repo OWNER/REPO --path skills/wan-i2v
```
